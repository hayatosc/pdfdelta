Original problem and desired outcome

The same source text can become incomparable when an unchanged endpoint is absorbed into a changed layout node. Better paragraph grouping has not recovered the selected missed prose changes. Separately, incomplete interpretation of non-text paint prevents the existing whole-document completion claim, even when a local text difference is proved.

Make local text comparison depend on checked source boundaries and source order instead of whole unchanged paragraphs. Demonstrate automatic recovery with correct finite extents on real development targets and genuinely unseen series. Preserve uncertainty wherever a correspondence, order, spacing, or paint premise is missing. Establish exactly what a restricted opaque-effect equivalence experiment can prove without representing it as complete text interpretation.

This is a new next-phase execution contract. It allows recovery evaluation to proceed independently of completeness research. It does not resume the old timed run, declare the old conjunctive goal achieved, or redefine the first practical release.
