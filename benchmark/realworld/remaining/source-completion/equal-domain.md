# Native equality domains without occurrence selection

The owning native interval path previously consumed only changed-range reviews.
An exact equal result from range discovery was discarded, even when enclosing
source boundaries could support a complete interval comparison. Discovery now
retains bounded equal-range locators separately from published reviews.

These locators have no proof authority. After existing whole-node and source-cut
reviews consume their work, the ownership pass reconstructs each equal candidate
from native evidence. It rechecks admitted source-only boundaries, whole-parent
glyph projection, source multiplicity, local closure, order and ownership. The
exact comparator must still prove equality with no unresolved local issue. No
equal B event is added, no occurrence edge is selected, and search or global
inventory obligations are not cleared.

Candidate retention is charged to the existing discovery ledger; final validation
shares the existing local proof ledger. Domains that overlap already owned source
remain declined. This implementation does not establish an independent fragment
partition around such overlap or admit other currently unsupported populations.

## Tests

one equal domain. The matching component remains exhaustive but has no mandatory
occurrence edge. Text source coverage is complete while relationship/search
uncertainty remains explicit. An unassigned glyph in the range or a native reading
that disagrees with the graph prevents the certificate.

## Natural result

The frozen six-pair pilot adds no native equality domain and no strict source
coverage. All six remain incomplete. Existing comparisons, reviews, masks,
certificates and unresolved reasons are preserved. Controller/processor and
Schedule C record slightly different cut-search work and entry-budget counters
because equal locators are now charged; their search remains nonexhaustive.
The other four comparison objects are identical to the preceding frozen version.

This confirms the synthetic proof path, not natural target recovery or progress
in the 36-pair completion rate. Before extending domain admission, inspect whether
actual equal candidates fail native closure, boundary proof, normalization,
ownership overlap or the shared work limit. Do not infer the failing condition
from the absence of a certificate, or waive paint inventory because content
matching succeeds.
