# Source-cut domains inside retained parents

## Implemented proof path

Internal source cuts can now supply a separately validated native interval
certificate. A serialized review supplies no ownership authority. The validator
reconstructs the declared matched population from immutable native evidence,
checks complete glyph projections and order, and closes it against native
inventory, paint and rival views. Every parent is partitioned into owned sources
and an explicit remainder. Shared glyphs cannot be split, and synthetic spacing
references never become owned glyphs.

Both enclosing boundaries must have survived source-only matching and dependency
checks. A boundary admitted only for its unpadded body additionally requires a
native, source-backed, unambiguous body-equality proof. Its outer spaces remain
outside the owned range. The selected interval must lie entirely after the first
boundary parent and before the last boundary parent.

Accepted endpoint cuts are checked against their actual parent edges. Internal
fragment cuts require complete native readings, preserved source projections,
equal fragments on both sides, and a fresh uniqueness census over every permitted
spacing interpretation of the entire population. The existing bounded occurrence
algorithm is reused. The original-to-expanded token map rejects a cut inside a
contracted space or shared glyph. The exact local comparator receives the selected
views under the existing shared work budget.

Whole-node certificates retain priority. Cut certificates use remaining proof
work and cannot overlap already owned native domains, strict comparisons or
earlier intervals. Their reports retain the original cuts and every parent
remainder. Reloading a report does not restore the private verification flag.
Neither a cut certificate nor its remainder changes paragraph identity, search
status, or global inventory.

## Verification

- A shared-parent fixture retains uncertain synthetic spacing outside an internal
  changed body. The body alone receives a cut certificate, while each parent's
  owned references plus remainder exactly reproduce its original references.
- Splitting only one side into different retained paragraphs preserves the same
  native input and the recovered interior references. Both ordinary and padded
  enclosing boundaries pass this control.
- A separate padded-endpoint fixture verifies that raw boundary-space differences
  stay outside the owned content, even when the enclosing graph normalization
  must be reconstructed from native evidence.
- Existing missing-glyph, mismatched-reading, unsafe-order and competing-cut
  controls continue to pass. The existing exact comparison and normalization
  tests cover the reused kernels.
- Final workspace checks: 2,505 passed, zero failed, two ignored; Clippy and
  formatting passed. Generated fixtures passed 48/48.

## Natural observations and remaining work

preceding frozen implementation. ECB keeps its seven whole-node interval
certificates; no new cut certificate is admitted in this pilot. All six remain
incomplete. No natural target recovery, new full-panel completion or universal
partition-invariance claim follows from the generated controls.

The two intermediate frozen experiments also produced no natural additions.
The first admitted only whole-node outer boundaries. The second revalidated
unpadded native boundary bodies but still required raw endpoint-parent text
equality. The final version instead retains exterior padding in the remainder
and proves that selected content excludes both boundary parents.

This implementation requires a plain matched interval. Complete-page
and anchored-page fallback populations, segmented page-region chains, row-order
frames, optional clipped boundary padding and content-edge refinements remain
outside this certificate. This frozen version also withheld ownership for all
local comparison uncertainty. The subsequent `domain-content.md` experiment
distinguishes completed content proofs from uncertain localization, retaining
every unresolved reason and the original masks. Outstanding proof obligations
remain visible in evaluation.
