## Contract and implementation

A source-bound native structure sequence can connect independently closed page regions. The page-local validator previously required every node to descend to a lower baseline, even when two monoline nodes share an exact baseline and have disjoint horizontal bounds. Segmented regions now try the existing spatial-row census after the original page census fails. No clipping padding or paint-order approximation is added. The report retains the row-census convention in each region that needs it.

The strict interval path previously skipped every review carrying native region metadata. It now reacquires the native sequence from immutable evidence and reconstructs both boundary premises, all page populations, glyph ownership and every page transition. It then runs the existing exact local comparator. Serialized region metadata and a B result alone confer no ownership; missing structure acquisition, nonmandatory boundaries, inferred correspondences, overlapping sources, paint or incomplete census still reject. Global inventory and relationship-search obligations are unchanged.

The reproduction was committed as `254c670` before the fix. A general fixture puts an independently tagged page region after a disjoint same-row prefix. Overlapping nodes, a glyph omitted from the graph while retained in raw evidence, reversed tag order and unknown paint must reject. The existing page-break, native-membership and row controls remain in the full suite.
