# Native interval source ownership

## Result

Seven bounded native intervals in the ECB annual comparison now supply source
coverage under their admitted boundary premises. Compared references increase
from 45,097 to 45,927 on the old side and from 45,085 to 45,912 on the new side.
The controller/processor, restrictions, Schedule C, Schedule SE and NIST
contingency controls retain identical coverage. All six pairs remain incomplete.
These are production-pipeline observations. Independent reconstruction now verifies
the seven intervals' native readings and literal masks. Boundary correspondence
and paint closure have not been independently adjudicated; no fixed-target
recovery or full-panel gain is claimed.

## Proof boundary

`NativeTextIntervalComparison` is separate from non-owning range reviews. A review
provides discovery hints only. Both endpoints must be admitted source-only
mandatory correspondences, with no inferred proposal or parent. The new path
rechecks complete glyph readings and order through the native census projection,
then closes the entire path including both boundaries against retained native
evidence, paint and rival views.

Every parent projection must account for all its source references. Each source
belongs to one path member; shared glyph ownership across members is rejected.
Only interior sources are owned, and the endpoint sources remain outside that
ownership. Sources already counted by strict comparisons or native equality
domains are reserved before this pass; overlapping interval claims are declined.
The existing exact group comparator retains normalization alternatives, source
origins and masks. It now accepts a shared proof-work ledger, without refilling
the budget between intervals. A comparison with unresolved normalization or
localization cannot supply this certificate.

The private in-process verification flag is skipped on serialization. Reloaded
reports cannot recreate interval ownership. Paragraph identity, relationship
mapping, search obligations and global inventory remain unchanged. No PDF names,
hashes, gold text or fixed page coordinates participate in admission.

## Verification and limits

- 2,502 workspace tests passed, zero failed, two ignored. Workspace Clippy and
  formatting checks passed. Generated fixtures passed 48/48.
- The 83-test native range suite covers the new connection. Added checks exercise
  exact literal-space masks, rejection of missing native glyphs and mismatched
  native readings, and loss of ownership authority after report serialization.
  Existing native closure controls still pass.
- Shared local and group comparator tests exhaust the caller's work across
  successive comparisons without replenishment.
- Removing only the new interval field makes every pilot comparison object equal
  to its prior frozen report, including candidates, original local comparisons,
  non-owning reviews, native equality domains and unresolved reasons.
- This initial path uses whole-node intervals with two admitted endpoints. It
  does not yet connect internal SourceCuts, inferred groups or retained segmented
  page-region reviews. Full proof availability under alternate paragraph
  partitioning remains unfinished. The existing group comparator can also retain
  uncertainty at reconstructed separators between interior nodes.
- This is one six-pair pilot, not two final fixed-panel captures. Binary and
  source snapshot, driver, exact capture records and raw reports are preserved
  under `benchmark/realworld/cache/source-completion/native-interval-v1/`.
  `native-interval-pilot.json` binds the before/after report and executable hashes.

The original completion goal remains unmet. Next work must connect source cuts
across parent partitions and address the independent inventory and search
obligations; source coverage gains alone do not satisfy it.

## Independent literal source and mask check

`audit_native_intervals.py` reads the frozen worker's version-8 transport, verifies
the document revision and native glyph count against the report, and reconstructs
each interval from complete mapped native glyph readings. No OCR or Unicode
normalization is used by this audit. All seven reported old/new strings match.
Owned sources are disjoint between intervals and from the reported boundary
sources. Mask positions resolve to the corresponding owned native glyphs.

A separate insertion/deletion dynamic program finds every possible unchanged
match edge on a minimum-cost path. Its complement gives the characters that must
change in every optimum. All seven minimum edit costs, mandatory character masks
and source projections agree with the Rust report. The independent oracle also
matches exhaustive path enumeration for 225 small repeated-character pairs.
The verified changes include the insertion of ` (SSM)`, footnote renumbering,
`central banks` versus `NCBs`, and `2023` versus `2024`.

This establishes the stated literal source/mask facts, not correct document-wide
matching, visible-text completeness or a fixed-target success. The preserved
worker responses, request and acquisition records remain under the same cache
directory. `native-interval-source-review.json` binds their hashes and records all
seven readings and changed positions.
