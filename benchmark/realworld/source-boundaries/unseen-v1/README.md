# Frozen unseen revision panel, version 1

Twelve natural revision series were selected after the V33 implementation, executable, lockfile and settings were frozen. The panel spans six publication families, English and Japanese, and seven independently identified producers. Each target is an ID-free literal source annotation resolved before any comparison; its core and permissible extent are identical. All 26 target/control page images were inspected. `inputs.json`, `targets.json` and the copied annotations are the canonical comparison registration; the earlier source-only inspection files remain as acquisition evidence.

Selection uses source availability and visible substantive prose revisions, never comparison outputs. The original IRS education-credit instruction candidate is retained as an acquisition failure: both PDFs produced zero glyphs with explicit clipping-path issues on every page. It was replaced before comparison by the IETF TLS recommendations. The original selection, failures, replacement and completed source-only inspections remain alongside this directory. The final twelve cannot be replaced after comparison. Any implementation or setting change retires this panel to exposed development.

Targets are the HIPAA purpose/scope paragraph; mobile-device and media-sanitization abstracts; EDPB video paragraph 15, online-contract paragraph 1 and payment paragraph 14; LoRA and Swin abstracts; the ViT regularization paragraph across two pages; FAA SMS cover paragraph 1; the TLS recommendations abstract; and the first METI/MIC common-guidelines paragraph. Footnote markers inside a selected paragraph and interior literal spaces remain raw evidence. Only external paragraph-number prefixes and outer padding are excluded. The ViT target excludes intervening page furniture and retains two independently resolved slices. The Japanese target contains a real addition about inclusion; radical/unified-ideograph substitutions alone cannot establish prose recovery.

Primary PDFs were obtained from NIST, EDPB, arXiv, FAA, RFC Editor/IETF and METI's joint publisher MIC. The MIC versions preserve the selected editions when METI returned HTTP 403. The first EDPB payment download returned HTTP 429; a later same-URL attempt succeeded. Historical RFC URL attempts returned HTTP 404; the IETF public archive supplied the old edition. Failed attempts and successful byte hashes are retained. No missing extraction is treated as empty successful text.

`source-review.json` binds the page captures, raw selectors and resolutions. `registration-status.json` records annotation completion before comparison. Development G1/G4 already pass; this registration itself establishes no unseen recovery or correctness result.
